# 武大宿舍水电监控集成（whu_meter）用户使用说明

> 适用版本：v1.1.2 及以上 | 适用环境：Home Assistant（Docker 或其他部署方式）

---

## 一、这个集成能做什么

本集成对接武汉大学水电服务平台，自动采集指定宿舍房间的电费数据，并在余额不足时发送告警邮件。安装配置完成后，无需任何手动干预，即可在 Home Assistant 中：

- 实时查看宿舍电费账户余额
- 查看昨日 / 今日 / 累计用电量
- 查看电表最近一次抄表时间
- 余额低于设定阈值时，自动向指定邮箱发送 HTML 告警邮件
- 将累计电量接入 Home Assistant 能源面板，做长期用电统计

---

## 二、安装

1. 下载安装包 `whu_meter_vX.X.X.zip`。
2. 解压后得到 `custom_components/whu_meter/` 文件夹。
3. 将整个 `whu_meter` 文件夹复制到 Home Assistant 配置目录下的 `custom_components/` 中（若该目录不存在请新建）。复制完成后路径应形如：

   ```
   /config/custom_components/whu_meter/
   ```

4. 重启 Home Assistant。

> Docker 部署可执行：`docker restart homeassistant`

---

## 三、首次配置（配置向导）

1. 进入 **设置 → 设备与服务 → 添加集成**。
2. 搜索 **武大水电**（或 WHU Meter）并点击。
3. 按向导依次完成四步选择：

   | 步骤 | 操作 |
   |------|------|
   | 1. 服务地址 | 保持默认 `http://zwhqbsd.whu.edu.cn` 即可 |
   | 2. 选择区域 | 例如「信息学部学生宿舍」 |
   | 3. 选择楼栋 | 例如「信息学部9舍」 |
   | 4. 选择楼层与房间 | 先选楼层（如 6 楼），再从房间列表中选中本宿舍（如 625） |

4. 确认后集成开始工作，第一次数据采集约在一分钟内完成。

---

## 四、集成选项

安装完成后，在 **设置 → 设备与服务 → 已配置** 中找到本集成，点击「配置」可随时调整以下选项：

| 选项 | 默认值 | 说明 |
|------|--------|------|
| 抓取频率 | 15 分钟 | 每隔多久从水电服务平台刷新一次数据 |
| 余额阈值 | 20 元 | 余额低于此值时触发「余额过低」状态与告警邮件 |
| 邮件告警开关 | 开启 | 控制是否在余额过低时发送邮件 |
| 邮件通知实体 | `notify.home_assistant_manager` | 用于发送邮件的 SMTP notify 实体，需选择邮件集成（如 SMTP）生成的实体 |

> 注意：邮件发送依赖 Home Assistant 中已配置好的 SMTP 集成（设置 → 设备与服务 → 添加集成 → SMTP，填入发件邮箱、授权码与 SMTP 服务器）。邮件通知实体必须选择 SMTP 类型，选择手机通知等其他类型的实体将无法发出邮件。

---

## 五、提供的实体

| 实体 | 类型 | 说明 |
|------|------|------|
| 账户余额 | 传感器 | 当前电费账户余额（元） |
| 累计总用电 | 传感器 | 电表累计用电量（kWh），属于 `total_increasing` 类，可直接加入能源面板 |
| 昨日用电 | 传感器 | 昨日全天用电量（kWh） |
| 今日用电 | 传感器 | 今日截至最近一次结算的用电量（kWh） |
| 上次抄表时间 | 时间戳传感器 | 电表最近一次抄表时间 |
| 余额过低 | 二元传感器 | 余额低于阈值时变为「开启」，是告警邮件的触发源 |

---

## 六、余额过低告警邮件

- **触发条件**：「余额过低」二元传感器由关变为开（即余额跌破阈值）。
- **邮件内容**：包含当前余额、余额/阈值比例条、昨日与今日用电、累计用电、上次抄表时间，以及「前往充值」按钮（一键跳转武大水电服务平台充值页）。
- **自定义邮件外观**：编辑集成目录下的 `custom_components/whu_meter/email_template.html`，即可修改邮件的排版与文案。模板中形如 `__SENS_BALANCE__` 的占位符会被自动替换为实际实体，请勿删除。
- **生效方式**：修改模板后，重启 Home Assistant（或在「设备与服务」中重新加载本集成），自动化会依据新模板自动重建。

> 重要提示：本集成会在每次启动/重载时依据 `email_template.html` 自动重新生成告警自动化。请直接修改模板文件本身，不要手动修改「自动化」界面中生成的自动化——手动改动会在下次重载时被覆盖。

---

## 七、接入能源面板（可选）

1. 进入 **设置 → 面板 → 能源**。
2. 在「电网消耗」中添加个体设备，选择本集成的 **累计总用电** 实体。
3. 电价为 0.58 元/度（以学校实际资费为准），可在能源面板的电价设置中填入，即可看到每日/每月电费统计。

## 八、常见问题

**1. 数据一直显示「未知」？**
检查宿主机能否访问 `http://zwhqbsd.whu.edu.cn`；查看 Home Assistant 日志中 `whu_meter` 相关报错。服务接口偶发超时属正常现象，下一个抓取周期会自动恢复。

**2. 没有收到告警邮件？**
依次检查：
- SMTP 集成是否已配置并能测试发送成功；
- 集成选项中的「邮件告警开关」是否开启；
- 「邮件通知实体」是否选择了 SMTP 类型的 notify 实体；
- 邮件可能在垃圾箱中。

**3. 想更换监控的房间？**
删除本集成后重新添加，重新走一遍配置向导即可（删除集成不会影响 SMTP 等其他配置）。

**4. 抓取频率和阈值如何调整更合适？**
日常监控建议保持默认 15 分钟；余额阈值建议设为「足够支撑 2~3 天」的金额，留出充值缓冲时间。

**5. 升级新版本？**
下载新版 zip，用其中的 `custom_components/whu_meter/` 覆盖旧目录，重启 Home Assistant 即可，原有配置自动保留。

**6. 如何卸载？**
在「设备与服务」中删除本集成，再删除 `custom_components/whu_meter/` 目录并重启 Home Assistant。
